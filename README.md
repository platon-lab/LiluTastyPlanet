# ЛИЛУ: ПОЖИРАТЕЛЬ ВСЕЛЕННЫХ

Игра на Python (pygame). Работает на ПК (Windows) и на Android.

## Структура
- `main.py` — вся игра: сюжет, катсцены, геймплей, управление, звук
- `make_music.py` — генератор музыки и звуков (уже запущен, файлы лежат в assets/)
- `assets/Lilu.png` — фото Лилу (фон уберётся автоматически)
- `assets/music/*.wav` — музыка (меню, лаборатория, космос, космические хрени, титры)
- `assets/sfx/*.wav` — звуки («ням», «БАМ», удар, клик)
- `assets/font.ttf` — (необязательно) шрифт с кириллицей
- `buildozer.spec` и `.github/workflows/android.yml` — сборка APK

## Запуск на Windows
1. Установи **Python 3.12** с python.org (галочка «Add python.exe to PATH»).
   Самая новая версия Python иногда ещё не поддерживается pygame.
2. Двойной клик по `install_and_run_windows.bat`. Он установит pygame и запустит игру.

Или вручную в командной строке, в папке с игрой:
```
python -m pip install pygame
python main.py
```

Управление на ПК: **WASD** или **стрелки**. Мышкой можно тянуть джойстик справа внизу.
Пауза: **P** или **Esc**. Звук вкл/выкл: **M**. Пропуск катсцен: кнопка «ПРОПУСТИТЬ».

## Как сделать APK (Android)

### Вариант 1. Без установки чего-либо, через GitHub (проще всего на Windows)
1. Создай бесплатный аккаунт на github.com и новый репозиторий (например, `lilu-game`).
2. Загрузи туда **всё содержимое папки lilu_game** (включая папку `.github`).
   Проще всего: на странице репозитория кнопка «Add file → Upload files», перетащить файлы.
3. Открой вкладку **Actions** → workflow «Build Android APK» запустится сам.
   Первая сборка идёт 20–40 минут.
4. Когда сборка зелёная, внизу страницы запуска в разделе **Artifacts** скачай `lilu-apk`.
   Внутри будет `.apk` — перекинь его на телефон и установи (нужно разрешить установку из неизвестных источников).

### Вариант 2. Linux или WSL2 на своём компьютере
```
pip install buildozer cython
buildozer android debug
```
APK появится в папке `bin/`.

### Для Google Play (AAB)
Google Play принимает формат AAB и требует подпись ключом:
```
buildozer android release
```
Потом подпиши AAB своим ключом и загрузи в Google Play Console (нужен аккаунт разработчика, разовый взнос 25 долларов).

## Как подкрутить баланс и музыку
В `main.py`:
- `CHAPTERS[...]["grow"]` — во сколько раз растёт Лилу в главе (больше = дольше глава)
- `GROWTH_PER_EAT` — сколько даёт каждый съеденный объект
- `TRACK_FOR_CHAPTER` — какая музыка в какой главе
В `make_music.py` — аккорды, темп (`bpm`) и `seed` мелодии. После правок запусти `python make_music.py`.
